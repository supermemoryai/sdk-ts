# Namespaces

## Overview

### Available Operations

* [list](#list) - List namespaces
* [get](#get) - Get namespace settings
* [update](#update) - Update namespace settings
* [delete](#delete) - Delete namespace

## list

Discover every namespace available to the caller, including its purpose, document volume, memory count, and lifecycle timestamps.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getNs" method="get" path="/ns" -->
```typescript
import { Supermemory } from "supermemory";

const supermemory = new Supermemory({
  apiKey: process.env["SUPERMEMORY_API_KEY"] ?? "",
});

async function run() {
  const result = await supermemory.namespaces.list();

  console.log(result);
}

run();
```

## update

Shape how Supermemory understands an existing namespace by updating the background context used during ingestion and memory formation.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="patchNsByNamespace" method="patch" path="/ns/{namespace}" -->
```typescript

const supermemory = new Supermemory({
  apiKey: process.env["SUPERMEMORY_API_KEY"] ?? "",
});

async function run() {
  const result = await supermemory.namespaces.update({
    namespace: "user_alex",
    body: {
      supportingContext: "This namespace holds Acme Corp support tickets.",
    },
  });

  console.log(result);
}

run();
```

## delete

Retire a namespace by permanently deleting its content, or preserve that knowledge by moving everything into another namespace first. Moves are queued and complete asynchronously.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="deleteNsByNamespace" method="delete" path="/ns/{namespace}" -->
```typescript
import { Supermemory } from "supermemory";

const supermemory = new Supermemory({
  apiKey: process.env["SUPERMEMORY_API_KEY"] ?? "",
});

async function run() {
  const result = await supermemory.namespaces.delete({
    namespace: "user_alex",
    body: {
      moveTo: "project_archive",
    },
  });

  console.log(result);
}

run();
```
